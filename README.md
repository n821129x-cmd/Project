# 每日工作追蹤系統

主管指派工作、員工回報進度的簡易系統（Google 試算表＋Apps Script）。

| 檔案 | 說明 |
|---|---|
| `apps-script/Code.gs` | 後端程式 |
| `apps-script/Index.html` | 網頁介面（直接用瀏覽器打開為預覽模式） |
| `apps-script/appsscript.json` | 時區與部署設定 |
| `index.html` | GitHub Pages 首頁，自動跳轉到 Apps Script 系統網址 |

> 重新部署成新網址時，記得把 `index.html` 裡的兩個網址一起改掉。


## 一、建立系統（約 10 分鐘）

1. 用**系統專用的 Gmail 帳號**（例如另開一個 tasks 帳號）登入 Google，建立一份新的 Google 試算表。
2. 試算表選單「擴充功能 → Apps Script」。
3. 在 Apps Script 編輯器：
   - 把預設的 `程式碼.gs` 內容全部換成 **Code.gs**
   - 左側「＋ → HTML」，檔名輸入 `Index`，內容貼上 **Index.html**
   - 「專案設定」勾選「在編輯器中顯示 appsscript.json」，把內容換成 **appsscript.json**
4. 回到試算表重新整理，上方會出現「代辦系統」選單。
5. 點「代辦系統 → ① 初始化工作表」，第一次會要求授權（試算表、Gmail），按允許。

## 二、填資料

> 第一次登入時會自動建立所有分頁，不一定要先執行「① 初始化工作表」。人員也可以登入後在「人員管理」新增。

- **人員**分頁：姓名、角色（主管／員工）、Email、LINE名稱、**帳號**、**密碼**
  - 預設管理者帳號：`n821129x`／密碼 `n821129x`（姓名「管理者」可改成真名）
  - 新增同事：加一列，給他帳號和密碼即可登入
  - 忘記密碼：直接在這張表改
- **設定**分頁：稱謂（預設「報告正翰」）、每日摘要時間等

## 三、部署網頁

1. Apps Script 右上「部署 → 新增部署作業 → 網頁應用程式」
2. 執行身分：**我**；誰可以存取：**任何擁有 Google 帳戶的使用者**
3. 複製網址，貼到「設定」分頁的「系統網址」，並把網址傳給同事
4. 選單「代辦系統 → ② 安裝自動排程」

## 四、日常使用

| 誰 | 做什麼 |
|---|---|
| 主管 | 「指派工作」分頁填寫送出，承辦人自動收到 Email |
| 員工 | 「我的工作」按「＋ 新增工作」可自己加工作（標示「自行新增」） |
| 員工 | 按「開始」開始計時，之後「回報」；做完按「提報完成」送主管確認 |
| 主管 | 員工提報完成後，在卡片上按「確認完成」或「退回」。預設不寄信（看待確認清單與早上摘要）；指派時勾選「🔔 員工提報完成時寄信通知我」的工作才寄信 |
| 主管 | 刪除：點開工作詳細資料，左下角「刪除」 |
| 主管 | 「統計圖表」看個案工作／臨時交辦完成度、各專案、各承辦人 |
| 主管 | 「人員管理」新增、編輯、刪除人員、重設密碼，可用 Excel 批次匯入 |
| 主管 | 「指派工作」下方可用 Excel 批次匯入工作（先預覽、標出錯誤列；勾選通知時每位承辦人只收一封彙整信） |
| 員工 | 回覆任何一封代辦信件，一件工作寫一行：`#T0012 狀態：完成 內容：已寄出` |
| 員工 | 按「今日回報／寄日報」，可複製回報說明或直接寄日報給主管 |
| 員工 | 也可以直接回覆指派信（狀態／進度／內容），每 10 分鐘自動匯入 |
| 主管 | 每天早上收到團隊摘要（逾期、未開始、等待外部過久） |

## 六、AI 功能（Gemini）

1. 第一次使用前，在 Apps Script 編輯器上方選 `setup` 函式按「執行」，授權「連線到外部服務」權限，然後部署新版本
2. 用最高管理者帳號登入 → **系統設定** 分頁
3. 依畫面說明到 Google AI Studio 建立金鑰，貼上 →「測試連線」→「儲存設定」

- 金鑰存放在 Apps Script 指令碼屬性，不會出現在試算表
- 員工：「今日回報／寄日報」→「寄出日報給主管」，信件包含 回報說明、系統自動產生的 AI 摘要、工作明細表格（員工沒有 AI 彙整按鈕）
- 員工當天沒寄日報，晚上 23:30 自動寄提醒（時間可在「系統設定」修改）
- 主管：「團隊總覽」每位員工旁的「AI 摘要」
- 最高管理者（帳號 n821129x，或角色填「管理者」）：「統計圖表」最上方「AI 辦理狀況分析」，以及「系統設定」
- 每天早上的主管摘要會列出前一個工作日「未寄日報」的員工

## 七、注意事項

- 改了程式後要「部署 → 管理部署作業 → 編輯 → 新版本」，網址不變。
- 登入用帳號密碼，登入狀態保留 14 天；密碼連錯 5 次會鎖 10 分鐘。員工只看得到自己的工作。
- 密碼以明碼存在試算表，請勿把試算表分享給員工，並請盡快更改預設管理者密碼。
- 回信格式讀不懂的信，會貼上「代辦系統/需人工確認」標籤並自動回信提醒。
- 一般 Gmail 帳號每天可寄約 100 封信。
- 已部署過舊版的話：直接覆蓋三個檔案、重新部署新版本即可，系統會自動補上「來源」「提報時間」「帳號」「密碼」等欄位，以及管理者帳號。
